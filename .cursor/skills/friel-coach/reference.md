# Friel Coach — Reference

Condensed Joe Friel frameworks for coaching decisions. Not a substitute for the original books.

## Seven zones (power, % FTP)

| Zone | Name | % FTP | Purpose |
|------|------|-------|---------|
| 1 | Active recovery | &lt; 55% | Recovery spins, flush legs |
| 2 | Aerobic endurance | 56–75% | Base miles, fat oxidation, durability |
| 3 | Tempo | 76–90% | Muscular endurance, race-like steady state |
| 4 | Threshold | 91–105% | FTP, time trial, climb pace |
| 5 | VO₂max | 106–120% | Short hard intervals, aerobic capacity ceiling |
| 6 | Anaerobic | 121–150% | Sprint repeats, neuromuscular power |
| 7 | Neuromuscular | max | Very short sprints, starts |

Sweet spot (common prescription): upper Z3 / low Z4 (~88–94% FTP).

## Performance Management Chart

| Metric | Friel name | Meaning |
|--------|------------|---------|
| CTL | Fitness | Chronic training load (~42-day weighted average) |
| ATL | Fatigue | Acute load (~7-day weighted average) |
| TSB / Form | Form | CTL − ATL |

**Form guidelines** (approximate — individual variance is large):

| Form | Typical feel | Coaching bias |
|------|--------------|---------------|
| &lt; −30 | Very tired | Rest or Z1 only |
| −30 to −10 | Training load absorbed | Normal training; watch quality days |
| −10 to +5 | Productive training zone | Good for key sessions |
| +5 to +25 | Fresh | Race or hard intervals |
| &gt; +25 | Possibly detrained | May lack race sharpness if sustained |

Rising CTL with manageable ATL = fitness building. CTL flat + high ATL = stagnation or overreaching risk.

## 12-week periodization (VeloPlanner mapping)

| Weeks | Phase | Emphasis |
|-------|-------|----------|
| 1–4 | Base | Aerobic volume, technique, Sunday endurance progression |
| 5–8 | Build | Limiter-specific intensity, race demands |
| 9–12 | Peak | Race simulation, openers, FTP tests, taper toward event |

Within each 4-week mesocycle: **3 load weeks + 1 recovery week** (volume ~70%, intensity maintained or slightly reduced).

## Limiter → focus (VeloPlanner)

| Focus | Primary limiter | Key sessions |
|-------|-----------------|--------------|
| Endurance | Aerobic durability | Long Z2 Sundays, tempo blocks late build |
| Sprint | Neuromuscular / anaerobic | Short openers, sprints when fresh |
| TT | Threshold / muscular endurance | Sweet spot, 20-min efforts, aero position |
| Hills | Climbing / sustained power | Hilly endurance, tempo on climbs |
| All-round | FTP / mixed demands | Balanced structure; sweet spot on Sundays |

One limiter per block. Secondary work only after primary sessions are secured.

## FTP & testing

- **FTP** ≈ best 60-min power or ~95% of 20-min test.
- **eFTP** (intervals.icu): modeled; drifts without recent maximal efforts.
- Test when: recovery week after build block, before peak phase, or ~4 weeks since last test.
- After test: update training zones; don't chase daily eFTP noise.

## RPE scale (1–10)

| RPE | Description |
|-----|-------------|
| 1–2 | Very easy — conversation effortless |
| 3–4 | Easy aerobic |
| 5–6 | Moderate — breathing deeper, still controlled |
| 7–8 | Hard — threshold / VO₂ territory |
| 9–10 | Very hard — short only |

Structured sessions should match planned RPE band. Chronic RPE &gt; planned → fatigue or intensity too high.

## Recovery hierarchy

1. Sleep (most underrated)
2. Nutrition & hydration around sessions
3. Easy Z1 spins on rest days (optional, ≤90 min)
4. Recovery weeks in the plan — non-negotiable
5. Full rest days — not "lost training"

## Taper (1–2 weeks pre-event)

- Reduce **duration** 40–60%; keep some **intensity** (openers).
- Last hard session 3–5 days before A-race.
- Form slightly positive; avoid arriving flat from too much rest or fried from too little.

## Weekly load rules of thumb

- CTL increase: ~5–8 TSS/day per week max for steady progress (roughly &lt;10% weekly TSS jump).
- After illness: return at 50% volume for 2–3 days, then ramp.
- Two bad readiness days in a row → treat as recovery need, not laziness.

## Readiness inputs (subjective + objective)

Weight in order when signals conflict:

1. Illness / injury / pain
2. Sleep quality & duration (stale sleep data = downgrade confidence)
3. HRV trend (not single point)
4. RPE vs expected for recent sessions
5. Form (TSB)
6. Motivation (lowest weight — but persistent dread can indicate overreach)
