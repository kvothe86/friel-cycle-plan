# Adaptive Cycling Coach (working title)

Ground-up rebuild of an adaptive cycling training app:
availability-driven daily planning, long-term periodisation around a goal,
dynamic re-planning from intervals.icu health and performance data,
two-way intervals.icu sync, and a Bluetooth ERG player.

See **[PLAN.md](PLAN.md)** for the full product and architecture plan.

Status: planning (no code yet). The previous app (VeloPlanner) is preserved in git history.
